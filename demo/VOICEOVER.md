# Overseer technical demo: voiceover script

Optional narration timed to `overseer-demo.mp4` (45 s, 1920×1080, 30 fps). The video is silent, and all of its explanation is on screen.

| Time | Scene | Narration |
|---|---|---|
| 00:00 – 00:04.5 | Title | Overseer is an enterprise AI gateway. It governs how employees use the language models the company pays for. |
| 00:04.5 – 00:10 | Problem | Premium AI access creates three risks: unmonitored spend, sensitive data sent to external models, and time spent on work that isn't business. |
| 00:10 – 00:17 | Architecture | Employees use an enterprise chat interface. Every request passes through a proxy, where a fast, low-cost Overseer agent checks intent before any premium model is called. Every request is logged. Managers are alerted only to jailbreak attempts. |
| 00:17 – 00:31.5 | Walkthrough | Each prompt is checked against the sender's job role. Work requests are forwarded. Personal data is masked. Off-scope requests are stopped at the gateway. Deliberate circumvention is blocked and reported. |
| 00:31.5 – 00:37 | Telemetry | Token use is recorded in real time and attributed by user, role and department in the manager dashboard. |
| 00:37 – 00:41.5 | Roadmap | Delivery runs in four phases: core proxy, Overseer agent, telemetry dashboard, then security hardening. |
| 00:41.5 – 00:45 | Value | Total visibility into AI spend, less wasted expenditure, and intellectual property that stays inside. |
