    The problem

    Premium AI access is easy to hand out and hard to account for.

    Once every employee has a seat on a frontier model, three costs start to grow where nobody can see them.

    • Unmonitored spend

      Personal and non-essential queries burn tokens on the company card with no owner and no budget line.

    • Data leaving the building

      Source code, contracts and customer records get pasted into public clients. One AKIA… key or a column of tax IDs is enough.

    • Productivity drain

      Tools bought for core work get used for trip planning, homework and side projects.

    The proxy

    One door between your people and the models.

    Employees chat through an enterprise interface instead of the public client. Every request travels through a single proxy layer that holds the API keys, routes to the right provider, and records what was sent.

    • A familiar chat experience, hosted under your own domain and SSO.
    • Provider keys stay on the server and never reach a browser.
    • Routes to Claude, OpenAI, or both, per team and per task.
    • Each request carries the user, role, model, and token count.
    The overseer agent

    A fast model reads the intent before an expensive model reads the prompt.

    The Overseer compares the meaning of each outgoing prompt with the sender's job role. Work requests pass, sensitive fields are masked, off-scope requests stop at the gate, and circumvention attempts are logged for a human.

        Five layers, built on a stack your team already ships.
        
      
          
        
        • Interface
          Next.js / ReactResponsive chat environment for employees.
          • 
        
        • Proxy
          Node.js or FastAPIIntercepts, authenticates and routes every prompt.
          • 
        
        • Overseer
          CrewAI + a fast, low-cost modelClassifies intent before the premium call.

        • Models

          • 
        
        • Telemetry
          PostgreSQL via SupabaseReal-time token counts, timestamps and user events.
